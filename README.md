# Beauty Salon — веб-приложение для салона красоты

Дипломный проект: полноценное веб-приложение для управления салоном красоты с онлайн-записью, личным кабинетом клиента и админ-панелью.

## О проекте

Приложение позволяет клиентам записываться на услуги онлайн, а администратору — управлять расписанием, мастерами и записями. Проект разработан в рамках дипломной работы по специальности «Разработчик веб и мультимедийных приложений».

## Функционал

**Для клиентов:**
Регистрация и авторизация
Личный кабинет
Просмотр списка услуг и мастеров
Онлайн-запись на удобное время
Просмотр и отмена своих записей

**Для администратора:**
Панель управления 
Управление записями клиентов
Управление списком мастеров и услуг
Просмотр свободных временных слотов

## Стек 

**Backend:** PHP
**База данных:** MySQL
**Frontend:** HTML5, CSS3, JavaScript
**Сервер:** Apache (локально — XAMPP / OpenServer)
